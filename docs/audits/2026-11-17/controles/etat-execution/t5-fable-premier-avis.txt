- So `insufficient_contribution = 0` only shows that no row had zero indicators.
- `docs/calculs/09-audit-2026-11/SOURCE_AUDIT.md` §16 asks for this coverage to be qualified.
- **Fix:** one read-only `GROUP BY` on `agg.player_power_matches`: role × number of non-null block columns, goalkeepers without `shot_stopping` (weight 0.60), and grades whose statistics row has `touches IS NULL`. Report these as "graded on partial support", separate from "valid".
