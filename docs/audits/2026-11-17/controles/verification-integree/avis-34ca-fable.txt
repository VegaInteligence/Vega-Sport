VERDICT: CHANGES_REQUESTED

One candidate-introduced defect blocks safe use of the snapshot path on production-shaped data, and the report does not yet measure it. I ran nothing; everything below is from reading the worktree against the inlined evidence.

## Findings

**1. Major — a withdrawn fixture is refused whenever a derived row names it, which freezes the whole edition.**
- **Mechanism:** `backend/vega/sources/snapshot.py:134-142` refuses a withdrawal for any dependency other than the provider keys (and Open Matchday's own statistics). The catalogue it reuses, `backend/sql/134_archive_repair_boundary.sql:21-33`, scans every `match_id` column in `core`, `agg` and `ops`.
- **Production shape:** `agg.match_forecasts.match_id` (`backend/sql/076_forecasts.sql:18-19`) holds a row for every unplayed fixture between two rated teams, whatever its source (`backend/vega/forecast.py:971-985`, `:1100-1101`). The repo README counts 1,984 forecasts on complementary editions.
- **Trigger:** the Open Matchday key contains the date (`backend/vega/sources/open_matchday.py:157`), so a postponement withdraws the old key. `remove` at `:287` then raises `MATCH_HAS_DEPENDENTS` and the folder's snapshot is rolled back.
- **Effect:** no new results for that competition until the old date plus three days (`forecast.py:988`) and a forecast refresh. The scope still records `ok` with `unmatched` > 0. The three English leagues this batch protects postpone most often.
- **Same class:** a reviewed `RETRACTIONS` entry for a finished match can never apply, because `agg.team_elo.match_id` (`backend/sql/032_power_rankings.sql:40`) blocks it.
- **Why tests pass:** `backend/tests/test_source_snapshots.py:515-517` and `:602-607` withdraw matches that have no forecast or Elo row. `:662-688` covers odds, events and statistics only.
- **Report gap:** `controles/verification-integree/dependances-1917.sql:7-11` checks five core families for the 2,249 scheduled fixtures, not the `agg` tables the guard reads. `FAILURE_MODES.md:1634` still says an unplayed match may leave.
- **Fix:**
  - Keep a reviewed allow-list of recomputable relations (`agg.match_forecasts`, `agg.match_lineup_forecasts`, and `agg.team_elo` for retractions only).
  - Remove their rows in the withdrawal transaction through a definer function; do not exempt `agg.*` wholesale.
  - Add a withdrawal test with a forecast row and a retraction test with Elo rows.
  - Count on RDS the scheduled complementary fixtures that have a forecast.

**2. Major, pre-existing and unchanged — `drop_copy` deletes a whole Open Matchday edition on catalogue presence alone.**
- **Witness:** `open_matchday.py:293-302` only checks that PitchAPI has an edition row for the season; `:305-321` then deletes every match, round, the edition and possibly the competition, outside all snapshot guards.
- **Exposure:** none today (zero copies measured for the 35 folders). It reopens at each season rollover if the copy is read before the native edition is registered, even an empty one.
- **Report gap:** this is the same failure class the branch fixed for archives (`primary_overlap`), but the plan does not list it as open.
- **Fix:** record it under VI-21 in `PLAN-VALIDATION.md`; require native fixture coverage, or hold, before any removal.

**3. Minor — preserved Transfermarkt history is hidden by the production reader.**
- **Refusal hides the list:** a refused refresh sets `error_code` (`backend/vega/transfermarkt.py:836-842`, `:1172-1178`). `api.player_transfer_reads` requires it NULL (`backend/sql/135_player_transfers.sql:44`), so the route returns 404 (`backend/api/src/routes/profiles.mjs:425-428`). The 55 keys survive in storage but not on the page.
- **Retracted moves stay published:** `api.player_transfers` (`135_player_transfers.sql:35`) ignores `absent_since`, so a move the provider dropped or re-keyed is served as fact.
- **Fix:** serve the last accepted read when `read_at` is set; expose or filter `absent_since`; add an HTTP test after a `HISTORY_*` refusal.

**4. Minor — three Transfermarkt writers still replace whole lists.**
- Market values (`transfermarkt.py:1133-1136`) lose rows on a truncated non-empty history, and they now feed the public value curve.
- Injuries (`:1233`) and squads (`:958`, `:1247`) are emptied by an empty answer.

**5. Minor — cost of the new guards is unmeasured at production size.**

- Fix: time one withdrawal and one grade publication on a production-size copy.

**6. Minor — operations.**

- **Restore:** `backend/vega/open_matchday_restore.py:308-310` takes about 40 table locks with NOWAIT; state that worker and backfill must be stopped.
- **Shoot-outs:** `backend/vega/sources/cup_periods.py:71-75` subtracts extra time from any unattested DFB shoot-out. That is an inference from 13 cases; record it per match.
