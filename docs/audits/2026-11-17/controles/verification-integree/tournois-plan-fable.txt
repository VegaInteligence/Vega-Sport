## 6. Commit B: rules

New `dashboard/shared/tournament-rules.js`, imported by the site and by `nations.mjs` (the API already imports from `dashboard/shared`).

**Group tables**
- **Points for a win:** World Cup up to 1990 two, everything else three.
- **Separating level teams**, declared per family, each with its regulation cited in a comment:

  | Family | Criteria |
  |---|---|
  | Euro 2020/2024/2028 | head-to-head (points, difference, goals, reapplied to a remaining subset), then overall difference and goals |
  | World Cup 1994–2022 | overall difference and goals, then head-to-head |
  | World Cup 1970–1990 | overall difference and goals |
  | anything else (World Cup to 1966, 2026, other tournaments) | none |

- **Still level:** the same position, `tied: true`. Row order inside a tie is difference, goals, name, as display order only.
- **A group with no finished match** has no positions.
- **Group identity:** the `group` field, else a round named `Group X`, else a declared final group.
- **Counted matches:** finished with a field score only; canceled, awarded and unscored never count.
- `groupTables(matches)` without rules keeps main's default, so main's test 12 stays green.

**1950 placing**
- Constant `FINAL_GROUPS["world-cup:1950"]`: round "Final Round", attested table Uruguay 5, Brazil 4, Sweden 2, Spain 1, source cited.
- The API claims a placing only when all the nation's final-round matches are scored and its two-point total equals the attested one.
- Stages: "Vainqueur" gold, "2e" silver, "3e" bronze, "4e". Otherwise "Poule finale" with no tone.
- `tournament-runs.js` adds depths "2e": 5 and "Poule finale": 4.

**Views**
- A declared final-group edition has no "Tableau" and opens on "Groupes".
- `view=tableau` falls back; recompute the effective view when the season changes inside the page.
- "Cette édition ne s'est pas jouée en groupes" appears only when no group exists.

**Editions**
- `tournamentEdition("world-cup", y)`: the collected competition for its own seasons (2026, 2022) and later years, the archive otherwise.
- A direct address to archive 2022 or 2026 keeps working.

**Conditional, only if the read-only check reproduces it**
- A run whose matches name no round gets no stage, and the tile shows no gauge.
- Following a team by its side id, with the name as fallback.

- **UX:** shared positions and position-less tables are less tidy than a full ranking, but nothing false is shown.

- **Compromise:** the "2e tour" label for 1974/1978/1982 stays wrong until a later SQL change.
