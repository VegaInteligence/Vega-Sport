# xA — passes décisives attendues

## Définition (fournisseur)

Le **xA** d'une passe est le xG du tir qu'elle a permis. Le xA d'un joueur dans un match est la somme des xA de ses passes menant à un tir. Champ PitchAPI : `expected_assists`. Vega ne le recalcule pas.

## Ce que Vega en fait

- **Match** : valeur affichée telle quelle parmi les chiffres clés (milieux, milieux offensifs, attaquants).
- **Saison** : total, par match et par 90 calculés comme pour le xG ([Agrégation d'une saison](../05-joueurs/01-agregation-saison.md)).
- **Accueil** : le xA d'un joueur n'est donné que s'il est renseigné sur tous ses matchs joués ; il sert de départage dans la liste des passeurs (`assists` décroissant, puis `xa`).
- **Effectif d'un club** : colonne « xG + xA » = somme saison du xG + somme saison du xA du joueur (un des deux absent compte pour 0, les deux absents → « — ») ([ClubScoutUI.jsx](../../../dashboard/frontend/src/components/ClubScoutUI.jsx#L1302)).

## Pourquoi le xA n'a jamais de centile

PitchAPI **ne publie pas les xA nuls** : un joueur qui n'a créé aucun tir n'a pas `xa = 0`, il n'a pas de valeur. La distribution des xA ne contient donc que les joueurs qui ont déjà créé quelque chose ; un centile la comparerait à un groupe trié d'avance.

Le xA est donc :
- affiché comme chiffre ;
- **exclu de tout centile, rang, indice Vega ou similarité** (`UNRANKED` dans [season-player.js](../../../dashboard/frontend/src/services/season-player.js#L80), `rankable: key !== "xa"` dans [scouting.js](../../../dashboard/frontend/src/services/scouting.js#L47), absent de `RANKED` dans [shared/player-profile.js](../../../dashboard/shared/player-profile.js#L104)) ;
- refusé dans un indice personnalisé : choisir le xA avec un poids > 0 renvoie « Un indicateur choisi ne permet pas un classement fiable. »
