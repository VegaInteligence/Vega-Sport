# Passation de l’audit Vega-Sport

Le ZIP exact est réparti en 5 fichiers Git. Après avoir récupéré cette branche, lance :

```sh
python3 reconstituer.py
```

Le script vérifie chaque partie et l’empreinte du ZIP reconstitué. Décompresse le résultat et ouvre **LIRE-D-ABORD.md** pour importer le bundle Git de l’audit. Le [prompt pour le modèle](PROMPT-COLLEGUE.md) donne le périmètre de reprise.
